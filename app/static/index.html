Cada quadradinho é um dos 384 números do vetor. Quanto mais as cores dos dois vetores coincidem, mais eles apontam para a mesma direção, e menor fica a distância.

SELECT id, titulo,
       VECTOR_DISTANCE(embedding, TO_VECTOR(:pergunta, 384, FLOAT32), COSINE) AS distancia
FROM   kb_docs
ORDER BY distancia
